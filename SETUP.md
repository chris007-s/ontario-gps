# Setup Instructions — Ontario GPS on GitHub Pages

## One-time setup (5 minutes)

### Step 1 — Create the repository
1. Go to https://github.com/new
2. Repository name: **ontario-gps**  (must be exact)
3. Set to **Public**
4. Do NOT check "Add README" (we have our own files)
5. Click **Create repository**

### Step 2 — Upload the files
1. On the new empty repo page, click **uploading an existing file**
2. Drag ALL files from this folder into the upload area:
   - index.html
   - manifest.json
   - sw.js
   - icon-192.png
   - icon-512.png
   - README.md
   - SETUP.md  (optional)
3. Scroll down, click **Commit changes**

### Step 3 — Enable GitHub Pages
1. In your repo, click **Settings** (top tab)
2. Left sidebar → **Pages**
3. Under "Branch", select **main** and folder **/ (root)**
4. Click **Save**
5. Wait ~60 seconds, then visit:
   **https://chris007-s.github.io/ontario-gps/**

### Step 4 — Install on your phone
**Android (Chrome):**
1. Open https://chris007-s.github.io/ontario-gps/ in Chrome
2. Tap the 3-dot menu → "Add to Home screen"
3. Tap "Add" — it installs like an app

**iPhone (Safari):**
1. Open https://chris007-s.github.io/ontario-gps/ in Safari
2. Tap the Share button (box with arrow)
3. Scroll down → "Add to Home Screen"
4. Tap "Add"

Done — tap the icon on your home screen to launch it like any other app.

## Updates
When you want to update the GPS, just re-upload index.html to GitHub.
Changes go live in about 60 seconds.
